# boboti orlik klopa laki — Interactive Photo Portfolio

Interaktivní webové portfolio ve stylu pexesa se 4 fotografiemi a dynamickým vodním pozadím.

## Funkce
- **Pexeso efekt:** Karty jsou na začátku otočené lícem dolů.
- **Interaktivita:** Kliknutím se odhalí fotka, v jeden moment lze odhalit maximálně 2 fotky.
- **Automatické otočení:** Po odhalení dvou karet se po 3 sekundách automaticky otočí zpět.
- **Vodní pozadí:** Prolínání tmavě modré a přírodní zelené barvy s plynulým efektem vody.
- **Responzivní design:** Mřížka 2×2 centrovaná na střed obrazovky.

## Technologie
- HTML5
- Moderní CSS3 (3D Transform, Flexbox, CSS Grid, animované přechody)
- JavaScript (ES6, Canvas API)
